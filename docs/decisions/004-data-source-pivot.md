# ADR 004: 1순위 데이터 소스를 Reddit에서 인벤 Aion 2 게시판으로 변경

**날짜**: 2026-04-19
**상태**: Accepted
**결정자**: 주찬
**교체 대상**: WEEK1_TASKS.md Task 5 (Reddit 수집기 → 인벤 크롤러)

## 맥락

프로젝트 초기 설계(PROJECT.md, WEEK1_TASKS.md)에서는 Reddit r/aion을
1순위 데이터 소스로 선택했다. 이유:

- Reddit은 공식 API 제공 (`praw` 라이브러리)
- 인증 및 데이터 취득이 간단
- "가장 쉬운 출발점"으로 MVP 완주 확률 제고

그러나 Week 1 착수 시점(2026-04-19)에 Reddit 개발자 앱 등록을 시도한 결과,
2025년 11월부터 도입된 **Responsible Builder Policy**로 인해 셀프 서비스
API 등록이 중단되었음을 확인.

## 현황

- 이전: preferences/apps에서 create app 클릭 → 즉시 OAuth 자격증명 발급
- 현재: 개발자 지원 폼으로 사전 신청 → Reddit 수동 검토 (목표 7일)
- 실제 보고 사례: "RBP 미준수 또는 세부 정보 부족" 등 일반적 사유로
  거부되는 경우 다수. 구체적 피드백 부재.
- 또한 정책에 "AI 학습에 Reddit 데이터 사용 금지" 조항 존재. 본 프로젝트는
  LLM을 분류 추론에 사용(학습 아님)하지만 엄격 해석 여지 있음.

## 대안 비교

| 옵션 | 장점 | 단점 |
|------|------|------|
| A. Reddit 승인 신청 | 공식 API, 안정적 | 7일+ 대기, 거부 가능성, MVP 완주 일정 지연 |
| B. 인벤 Aion 2 게시판 크롤링 | 즉시 시작 가능, 한국어 소스 | robots.txt/저작권 주의 필요 |
| C. Pushshift 등 아카이브 | 대안 접근 | 2023년 이후 접근 제한, 실시간성 낮음 |

## 결정

**옵션 B 선택: 인벤 Aion 2 게시판을 1순위 데이터 소스로 변경.**

## 근거

1. **한국 커뮤니티가 Aion 2 여론의 본진** — NCSoft는 한국 회사, 주 사용자
   한국. Reddit r/aion은 원조 Aion(구작) 영문권 유저 중심이라 Aion 2
   관련 콘텐츠가 상대적으로 적음. 정보 가치가 한국 소스 > Reddit.

2. **DE 포트폴리오 관점에서 더 강력한 스토리**
   - "공식 API 호출"은 튜토리얼 수준의 작업
   - "HTML 구조 분석 → 한국어 커뮤니티 크롤러 설계"는 실무 난이도
   - 실제 기업 DE 업무는 깔끔한 API보다 이런 "비정형 소스 통합"이 다수

3. **한국어 NLP 실전 경험** — 한국 취업 시장에서 Gemini 한국어 감성
   분류 경험은 영어 Reddit 분석보다 직접적으로 가치 있음.

4. **MVP 완주 우선 원칙 준수** — Reddit 승인 대기(7일+)로 일정이
   밀리면 동기 상실 위험. 즉시 착수 가능한 소스로 전환.

5. **외부 환경 변화 대응 경험** — 이 피벗 자체가 면접 스토리. "계획대로
   안 됐을 때 대응"은 DE 면접 단골 질문.

## 실행 계획

### 데이터 소스 상세

**인벤 Aion 2 게시판 구조:**
- 메인: https://aion2.inven.co.kr/
- 게시판 URL: `https://www.inven.co.kr/board/aion2/{board_id}`
  - `6388` — 자유 게시판 (1순위, 여론 가장 활발)
  - `6444` — 팁과 노하우 게시판
  - `6447` — 서버 게시판
  - `6451~6453` — 클래스별 게시판 (호법성, 마도성 등)
- 게시글 상세: `https://www.inven.co.kr/board/aion2/{board_id}/{post_id}`
- 모바일 버전(`m.inven.co.kr`) 존재 — HTML 구조 종종 더 단순

### 기술 스택 변경

- `praw` 제거
- `requests` + `beautifulsoup4` 추가 (이미 `pyproject.toml`에 포함)
- 선택적으로 `lxml` 추가 (BeautifulSoup 파서, 속도 향상)

### 수집 정책 (robots.txt 및 저작권 준수)

**반드시 준수할 것:**
- User-Agent 명시: `legion-voice-tracker/0.1 (aion2-guild; +contact@example.com)`
- 요청 간격 **3~5초 이상** (서버 부담 최소화)
- 한 번 실행 당 페이지 수 제한: 각 게시판 최근 2~3페이지만
- `robots.txt` 확인 및 준수 (첫 착수 시 수동 확인)
- 제목/본문 전문 수집은 DB 내부 저장 목적에 한정

**대시보드 노출 정책 (저작권 리스크 회피):**
- 게시글 원문 제목/본문을 대시보드에 그대로 노출하지 않음
- 대시보드에는 LLM이 생성한 `issue_summary`(2차 저작물)만 표시
- 원문 접근은 **인벤 원문 링크**로만 제공
- 공개 API로 원문 응답 금지 (집계 수치만 반환)

### 저작권 주의 상세 (인벤 이용약관 기반)

인벤 공지: "콘텐츠는 저작권법의 보호를 받으며, 무단 전재·복사·배포를 금합니다."

**해석 및 대응:**
- "전재·복사·배포 금지" → 원문을 그대로 재공개하면 안 됨
- 분석/통계 목적의 수집은 공정이용 여지 있음 (저작권법 제35조의5)
- 본 프로젝트는 "사적 이용 + 통계 제공" 목적으로 한정하여 리스크 회피
- 원문 노출 없이 링크만 제공 시 "인용" 및 "공정이용" 범위 내

## 다음 우선순위 (Week 2 이후)

- 2순위: 디시 Aion 갤러리 (HTML 구조 까다로움, 방어적 크롤링 필요)
- 3순위: YouTube 댓글 (Data API 공식, 할당량 관리 필요)
- Reddit은 **제외** (승인 신청은 하지 않음 — 시간 대비 가치 낮음)

## 결과 및 위험

**긍정:**
- Week 1 일정 지연 없이 즉시 착수 가능
- 포트폴리오 스토리가 오히려 강화됨
- 한국어 NLP 역량을 실전에서 검증

**위험 및 대응:**
- HTML 구조 변경 리스크: 파서를 모듈화하여 변경 시 부분 교체 가능하게 설계
- IP 차단 리스크: 요청 간격 엄수, User-Agent 명시, 과도한 병렬 요청 금지
- 저작권 리스크: 원문 비공개 정책 철저 준수, 대시보드는 집계/요약만 노출
